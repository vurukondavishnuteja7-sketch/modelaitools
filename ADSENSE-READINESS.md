# AdSense readiness checklist

This package has a reserved clearly labelled ad slot on the homepage, About/Contact/Privacy/Terms/Disclaimer pages, XML/HTML sitemaps, robots.txt, and a starter ads.txt file with no invented publisher ID.

Before applying: publish original helpful content, remove empty or placeholder pages, make navigation work, ensure mobile usability, confirm privacy disclosures describe actual provider/file handling, use your AdSense publisher ID and exact ads.txt record from your own account, comply with regional consent requirements, and test performance. Ad placement alone does not make a site eligible, and approval is not guaranteed.
