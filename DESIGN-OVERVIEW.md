# MODEL AI — Premium Neon/Gilded Website

This build applies the supplied dashboard reference to the actual pages: near-black glass panels, restrained gold trims, violet/pink neon lighting, a custom cinematic character/robot hero artwork, a functional home AI prompt form, tool cards, responsive navigation, profile panel and promotional cards.

## Files changed
- `index.html`: redesigned dashboard, primary nav, sidebar, hero, home chat prompt, provider/capability row, right-side profile and feature promos.
- `assets/premium-theme.css`: premium dark theme, responsive layout, glows, hover states, orbit shimmer and reduced-motion fallbacks.
- `assets/model-ai-cosmos.webp`: custom generated hero artwork (not a screenshot of the UI).
- `assets/firebase-auth.js`: updates the right-rail account identity after Firebase authentication, while preserving existing login flows.
- `favicon.svg`: gold crown brand mark.

The reference is a visual design direction. API keys are not embedded in source files; chat/image functionality continues to rely on Cloudflare Pages Functions and the configured server-side keys.
